═══════════════════════════════════════════════════════════════
  🆘 AIDE RAPIDE
═══════════════════════════════════════════════════════════════

❓ Le site ne s'affiche pas ?
   → Vérifiez que le serveur tourne
   → Regardez l'onglet PORTS (dans Codespaces)

❓ Mes changements ne s'affichent pas ?
   → Sauvegardez : Ctrl+S (Cmd+S sur Mac)
   → Rechargez : Ctrl+R
   → Videz le cache : Ctrl+Shift+R

❓ Erreur JavaScript ?
   → Appuyez sur F12
   → Regardez la Console (messages en rouge)
   → Vérifiez virgules, guillemets, accolades

❓ Comment annuler une modification ?
   → git checkout -- nom_du_fichier
   → git reset --hard (annule TOUT)
